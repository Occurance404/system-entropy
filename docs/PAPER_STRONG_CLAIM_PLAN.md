# Strong-Claim Paper Plan (OpenRouter, ~$200–$350)

## Primary Claim (recommended)
**Non-stationarity hurts agent task completion.**  
Across multiple task families and multiple OpenRouter models, the *shock* condition (mid-run requirement/schema change) decreases validator success rate and increases run length (steps/tokens) relative to baseline.

This is strong because it is:
- falsifiable (success is validator-based),
- model-agnostic (multiple providers/models),
- reproducible (fixed scenario seed + fixed suite + logged manifests).

## Experimental Setup (what to run)
### 1) Models
Create a models file from `benchmarks/models.openrouter.paper.template.json:1` by replacing `model` IDs with the OpenRouter model IDs you want.

Put your key in env:
```bash
export OPENROUTER_API_KEY="..."
```

### 2) Suite
Use `benchmarks/suite_paper_v1.json:1` (3 families × baseline/shock = 6 conditions).

### 3) Reproducibility toggles (recommended)
```bash
export SANDBOX_BACKEND=local
export SANDBOX_PER_RUN=1
export SCENARIO_SEED=0
export REQUEST_TOOLS=auto
export REQUEST_LOGPROBS=auto
```

### 4) Run count (fits ~$200)
Start with **3 models × 6 scenarios × 10 repeats = 180 runs**.

If you need to cut cost:
- drop to 2 models, or
- drop repeats to 5 (90 runs), or
- reduce `max_steps` in the suite.

## Commands (end-to-end)
One-command sweep + tables + dataset packaging:
```bash
./scripts/run_paper_sweep_openrouter.sh benchmarks/models.openrouter.paper.json benchmarks/suite_paper_v1.json 10
```

Manual (same steps):
```bash
python experiments/run_benchmark.py --models benchmarks/models.openrouter.paper.json --suite benchmarks/suite_paper_v1.json --repeats 10 --probe-mode off
python analysis/analyze_benchmark.py --results data/results/<benchmark>.csv
python analysis/analyze_shock_deltas.py --results data/results/<benchmark>.csv
python analysis/package_benchmark.py --results data/results/<benchmark>.csv --copy-logs --copy-manifests
```

## What to report (tables/figures)
Primary:
- Success rate per (model, family, condition) and the **delta** (shock − baseline) with 95% bootstrap CI.
  - Generated by `analysis/analyze_shock_deltas.py:1`.

Secondary:
- Median steps and tokens (from `analysis/analyze_benchmark.py:1` summary).
- Failure mode snippets from JSONL logs (qualitative section).

Figures (auto-generated in the packaged dataset):
- `figures/fig_success_rates.png` and `figures/fig_shock_deltas.png` from `analysis/plot_paper_figures.py:1`.

## Pre-registered analysis decisions (avoid “metric fishing”)
- Success is `validation_passed == True`.
- Main comparison is paired by family: `<family>_baseline` vs `<family>_shock`.
- Probe mode for main results is **off** (reduces confounds and cost).

## Optional add-ons (if you extend to ~$350)
1) **Probe study (diagnostics)**: run a smaller subset with `--probe-mode shock --probe-branches 3` to get SCR at perturbation steps.
2) **Robustness**: repeat with `SCENARIO_SEED=1,2,3` and report variance.
3) **Mitigation ablations**: compare `REQUEST_TOOLS=on/off` or other control knobs, but keep the primary claim unchanged.
